Tiga Perbedaan yang Saya Rasakan


1. Cara Menulis Program

Pada pemrograman prosedural, saya menulis instruksi secara berurutan. Sementara pada OOP, saya perlu membuat class terlebih dahulu, kemudian membuat objek dari class tersebut. Awalnya OOP terasa sedikit lebih panjang, tetapi susunan kodenya lebih teratur.

2. Cara Menyimpan dan Mengelola Data

Dalam versi prosedural, saya menyimpan data buku menggunakan array. Sedangkan dalam OOP, setiap data buku dimasukkan ke dalam objek melalui constructor. Dari latihan ini, saya mulai memahami bahwa OOP dapat menggabungkan data dan fungsi yang berkaitan dalam satu class.

3. Penggunaan Kembali Kode

Pada versi prosedural, saya menggunakan perulangan untuk membaca data yang tersimpan di dalam array. Pada versi OOP, saya cukup membuat objek baru dari class Buku tanpa harus menulis ulang struktur class. Menurut saya, cara ini akan lebih membantu ketika program memiliki banyak data atau fitur tambahan.
